Método y fuentes · V10.4

El visor está diseñado para orientar visitas, verificación y acompañamiento. La información climática actúa como señal territorial de apoyo; no constituye por sí sola una confirmación de desabastecimiento.

1. Clasificación climática de los sistemas

Se conserva la clasificación P1 / P2 / P3 de la base técnica: alta, media y menor exposición climática, construida con precipitación CHIRPS y anomalía térmica ERA5-Land para el corte analizado.

2. Prioridad municipal de vigilancia

La prioridad municipal se calcula a partir de la prioridad operativa de los sistemas con información suficiente. Se usa un índice ponderado 3–2–1: Inmediata = 3, Reforzada = 2 y Rutinaria = 1. El índice municipal es (3×Inmediata + 2×Reforzada + Rutinaria) / sistemas clasificados. La lectura técnica se conserva con los umbrales: Alta ≥2,5; Importante ≥2,0; Moderada ≥1,5; Referencia <1,5. En V10.4 se mantiene la comunicación simplificada: Alta → Prioridad alta; Importante + Moderada → Seguimiento; Referencia → Rutinaria; sin sistemas clasificables → Sin información.
