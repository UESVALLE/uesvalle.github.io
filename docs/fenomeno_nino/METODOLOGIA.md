# METODOLOGÍA — Fenómeno de El Niño / UESVALLE

## Alcance
Informativo y preventivo.

El módulo busca:
1. representar espacialmente los sistemas de abastecimiento;
2. superponer información climática e hidrológica oficial;
3. identificar zonas que ameritan mayor seguimiento;
4. orientar el diagnóstico posterior por formulario.

No declara afectación sin verificación.

## Conceptos
- Exposición: condición climática/hidrológica territorial.
- Vulnerabilidad: características del sistema.
- Prioridad informativa: combinación de exposición, vulnerabilidad e impacto.
- Afectación confirmada: requiere reporte/verificación.
